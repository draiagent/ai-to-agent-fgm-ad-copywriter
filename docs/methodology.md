# FGM Methodology

## 1. FGM 解決的不是「文筆」，而是「推論路徑」

廣告常見錯誤是直接從產品名稱跳到價值判斷：好、強、專業、頂級、有效。FGM 要求 Agent 把中間推論攤開。

```text
證據 → 可驗證事實 → 觀眾尚未知道的缺口 → 觀眾自行形成的意義
```

因此真正的轉化力來自「證據與推論距離夠短」。

## 2. Fact
Fact 不是品牌說過的話，而是可以回答「你怎麼知道？」的句子。

差的 Fact：
> 採用頂級材質，保溫效果超強。

較好的 Fact：
> 杯身為雙層真空不鏽鋼結構；容量 500 mL。

## 3. Gap
Gap 是「資訊尚未完整揭露」所形成的認知張力。

例如：
> 同樣看起來是不鏽鋼杯，為什麼有些裝冰水後外壁會冒水珠？

它可以由後續的真空層、熱傳與結露機制回答，因此是有效 Gap。

## 4. Meaning
Meaning 是觀眾自己完成的結論，例如：
> 如果我常放包包裡，外壁不容易結露對我更方便。

廣告不必直接說「這就是最適合你的杯子」。

## 5. Agent Layer
FGM 核心只保留 Fact / Gap / Meaning；Evidence、Hook、Script、Visual、Adapt、Verify 是執行層。如此可同時維持方法論簡潔與 Agent 可操作性。

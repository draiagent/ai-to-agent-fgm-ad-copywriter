# Usage

## 最短指令

```text
用 FGM 跑這個產品。
```

## 建議完整指令

```text
使用 fgm-ad-copywriter。
產品：<產品資料>
客群：<目標客群>
平台：Instagram Reels
長度：30 秒
目標：導流產品頁
限制：不可使用未驗證療效或比較性宣稱
```

## Agent 執行順序

1. 先列 Evidence Table。
2. 對 Evidence 產生 Fact ID。
3. 每個 Gap 綁定至少一個 Fact ID。
4. 每個 Meaning 說明由哪些 Fact 支持。
5. 再產出 3 個 awareness angle。
6. 最後才做畫面、圖卡與 CTA。
7. 輸出 Verification Report。

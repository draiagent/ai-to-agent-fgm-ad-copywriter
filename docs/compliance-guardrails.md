# Compliance Guardrails

本 Skill 不是法律審核器。它的責任是降低不實、誤導與不可驗證宣稱進入廣告的機率。

## 高風險訊號

- 疾病治療、預防、逆轉、保證效果。
- 保證收益、穩賺、零風險。
- 未附條件的「第一」、「唯一」、「最好」。
- 未證實的醫師／專家／機構背書。
- 虛假稀缺、虛假倒數、虛構見證。
- Before/After 與數據對比沒有來源或條件。

## Agent 行為

遇到高風險宣稱時：
1. 標記 `REVIEW`。
2. 將宣稱改寫成可被 Fact 支持的範圍。
3. 若無法安全改寫，直接移除。
4. 保留需要人工法規審核的項目。

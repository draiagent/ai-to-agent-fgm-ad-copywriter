# 六張技能圖卡文字索引

圖卡 v0.1.0，套件 v0.1.2。完整圖卡入口見 [assets](../assets/README.md)。

## 01｜技能總覽
FGM 廣告文案技能：從產品證據到廣告說服力。
Fact 事實：去掉形容詞，留下可驗證資訊。
Gap 缺口：揭示已知與未知之間的資訊落差。
Meaning 言外之意：用事實與畫面讓觀眾形成判斷。
輸入：產品資料、規格、網址、截圖。產出：事實提煉、廣告腳本、分鏡、圖卡文案。
先有證據，再設計說服力。

## 02｜FGM 三步核心
Fact：這句話的證據在哪裡？
Gap：觀眾為什麼想繼續看？
Meaning：這個結論是否超出證據？
吸引注意，也要兌現答案。

## 03｜Agent 九步執行
01 Evidence 蒐集證據；02 Fact 提煉事實；03 Gap 設計缺口；04 Meaning 建立意涵；05 Hook 撰寫開場；06 Script 完成腳本；07 Visual 規劃畫面；08 Adapt 適配媒體；09 Verify 檢查驗收。

## 04｜三項核心檢查
事實有證據：保留來源、原文與適用範圍，品牌自述不等於已驗證事實。
缺口不誤導：Hook 提出問題，內容提供答案，不靠聳動標題製造錯誤期待。
意涵不越界：旁白、字幕與畫面一起檢查，不暗示證據未支持的效果。

## 05｜技能使用與交付
啟動指令：用 FGM 跑這個產品。
提供產品資料、目標客群、發布平台。
問題認知：理解痛點。方案認知：理解方法。產品認知：理解差異。
交付：事實提煉表、三組廣告腳本、分鏡與旁白、媒體適配文案。

## 06｜驗收與修正閉環
檢查 → 修正 → 再驗收 → 交付。
PASS：檢查通過，可交付。REVIEW：證據或宣稱待人工確認。FAIL：缺少關鍵證據或內容誤導。
不合格時退回對應步驟；未通過時不列為可發布版本。
內容驗收通過不等於保證廣告轉化，實際成效仍需投放測試。

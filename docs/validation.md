# Validation

## FGM QA Matrix

| Check | PASS | REVIEW | FAIL |
|---|---|---|---|
| Fact | 可追溯且條件完整 | 來源弱或缺少部分條件 | 無來源／錯誤／捏造 |
| Gap | 真實疑問且後文可回答 | 稍偏標題化 | 純 clickbait／誤導 |
| Meaning | 在 Fact 支持範圍內 | 有輕微推論跳躍 | 超出證據、保證效果 |
| Hook | 3 秒內清楚建立 Gap | 略長或重點不明 | 與正文無關 |
| Script | 三層認知切角明確 | 部分重複 | 三組只是改寫同一版 |
| Visual | 能支撐 Fact / Meaning | 部分只是裝飾 | 畫面造成錯誤暗示 |
| Compliance | 無明顯高風險宣稱 | 需人工審核 | 明顯不可接受宣稱 |

## 完成條件

只有以下條件同時成立才可標記 `PASS`：
- 重要 Fact 全部有來源。
- 三個 Awareness angles 彼此差異明確。
- Hook 能回指 Fact。
- Meaning 沒有超過證據。
- Visual 沒有製造額外誤導。
- 沒有未處理的高風險宣稱。

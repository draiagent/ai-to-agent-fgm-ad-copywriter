# AI 寫廣告，如何從「很會說」走向「值得相信」？

你是否遇過這種情況？

把產品資料交給 AI，幾秒鐘就收到一篇文案：「頂級品質、革命性技術、前所未有的體驗。」

讀起來很熱鬧，卻回答不了一個問題：

**消費者為什麼要相信？**

在 AI to Agent 的時代，我們可以把廣告創作設計成一套有證據、有步驟、能檢查與修正的工作流程。這正是 **FGM 廣告文案技能 `fgm-ad-copywriter`** 的核心。

**① Fact｜事實：先找出站得住腳的資訊**

第一步，先把形容詞拿掉。

「超強保溫」是宣稱；「規格標示容量 500 mL」是可以回到資料核對的資訊。至於能保溫多久，還需要相應的測試條件與結果。

Agent 必須追問：來源在哪裡？是否對應同一款產品？數據有沒有單位與條件？

**資料支持到哪裡，文案就說到哪裡。**

**② Gap｜缺口：讓觀眾產生值得追問的疑問**

有了事實，接著思考：觀眾知道什麼？還不知道什麼？

例如：「挑杯子只看容量，你是不是漏看了另一項規格？」

這句話創造了資訊落差，後文就必須說清楚是哪項規格，以及它能提供什麼資訊。

Gap 的任務，是讓人願意繼續理解。開場提出的問題，內容必須兌現答案。

**③ Meaning｜言外之意：讓受眾形成合理判斷**

當事實與情境排列清楚，觀眾才有機會自己想到：

「原來我選產品時，也應該注意這件事。」

Meaning 讓產品資訊連結到使用者需求，但不能偷偷增加證據沒有支持的結論。

規格寫著雙層真空結構，不代表我們就能暗示「放進包包一定不漏水」。文字、字幕與畫面，都需要守住同一條界線。

**從三步方法，走向九步執行**

教學時，記住 **Fact → Gap → Meaning**。

實際交給 Agent，則依序完成：

**證據 → 事實 → 缺口 → 意涵 → 開場 → 腳本 → 畫面 → 媒體適配 → 驗收。**

每一步都有明確產物，讓下一步有依據，也讓出錯時找得到需要修改的位置。

使用時，可以直接說：

「用 FGM 跑這個產品。」

再提供產品資料、目標客群與發布平台，要求 Agent 交付事實提煉表、三種認知切角的廣告腳本、分鏡與旁白，以及圖卡和社群文案。

三種切角分別面向：正在理解問題的人、正在比較解決方案的人，以及正在評估產品的人。內容要回應不同疑問，不能只是同一篇換幾個詞。

**交付之前，還有最後一道功課**

事實能否追溯？Hook 是否有答案？Meaning 是否越界？畫面有沒有造成額外誤導？

檢查後，給出 **PASS、REVIEW 或 FAIL**；需要修正就退回對應步驟，再次驗收。

而且，內容通過驗收，仍不代表保證轉化。真正的廣告成效，需要投放測試與數據回饋。

當 AI 能依證據創作、依規則檢查、發現問題後修正，我們就能把專業判斷整理成可重用的技能。

下一次請 AI 寫廣告前，先問自己：

**「我交給它的，是一串想說服人的形容詞，還是一組能讓人相信的證據？」**

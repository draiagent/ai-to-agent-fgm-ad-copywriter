# Fact Verification

## Fact 判斷五問

1. **來源在哪裡？**
2. **來源是不是在講同一個產品／版本？**
3. **有沒有條件、單位、時間或比較基準？**
4. **這句是觀察到的事實，還是品牌推論？**
5. **換一個人檢查，能不能得到相同答案？**

## 禁止偷換

- 「含有 X 成分」≠「一定產生 Y 效果」。
- 「實驗中觀察到」≠「所有使用者都有效」。
- 「某條件下優於對照」≠「全面最好」。
- 「使用者回饋」≠「客觀功效證明」。

## 建議欄位

Evidence ID / 原文 / 來源 / 日期 / 適用產品 / Fact / Confidence / 限制。
